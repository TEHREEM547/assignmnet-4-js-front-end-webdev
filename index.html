Question 5: Electricity Bill Calculator Take the number of electricity units consumed and calculate the bill using these rates: - First 100 units: Rs. 10 per unit - Next 100 units: Rs. 15 per unit - Above 200 units: Rs. 20 per unit Calculate the bill using cumulative rates. For example, the first 100 units are charged at Rs. 10 each, and only the units above 100 are charged at the next rate.

    let units = Number(prompt("Enter electricity units:"));
let bill;

if (units <= 100) {
    bill = units * 10;
} else if (units <= 200) {
    bill = 100 * 10 + (units - 100) * 15;
} else {
    bill = 100 * 10 + 100 * 15 + (units - 200) * 20;
}

console.log("Electricity Bill: Rs. " + bill);

solution

Electricity Bill: Rs. 120
